# Generative Fireworks

## Overview

This project explores the development of a generative poster based on the theme of fireworks.

The project was developed through four stages:

1. Simple
2. Preset Style
3. Interactive
4. 3D-like

I started with a simple firework and gradually developed it into a more complex generative space by adding visual style, user interaction, and spatial depth.

---

## 1. Simple

### Concept

In the first stage, I created a simple generative firework using radial lines. A single center point was used to create lines spreading in different directions.

### Prompt

> Create a simple generative firework using radial lines. Place one firework in the center of a black background and create a minimal poster with simple geometric lines.

### Result

The result is a simple firework made of radial lines spreading from one center point.

---

## 2. Preset Style

### Concept

In the second stage, I developed the simple firework by adding irregular lines and small particles. I wanted to create a more organic and dynamic visual appearance.

### Prompt

> Apply a brush-like and organic visual style to the simple firework. Add irregular lines, subtle variations in transparency, and small particles around the firework while maintaining a minimal black background.

### Result

The basic firework was transformed into a more organic form by adding brush-like lines and particles.

---

## 3. Interactive

### Concept

In the third stage, I introduced user interaction. The number of fireworks, their size, and the number of particles can be controlled using interactive sliders.

### Prompt

> Create an interactive generative fireworks poster. Allow the user to control the number of fireworks, their size, and the number of surrounding particles using interactive sliders.

### Result

Different fireworks compositions can be generated by changing the slider values.

---

## 4. 3D-like

### Concept

In the final stage, I created a larger fireworks scene. Different sizes, positions, and transparency levels were used to create a sense of depth.

### Prompt

> Create a 3D-like generative fireworks scene. Arrange fireworks at different depths using variations in size, transparency, and position. Create a sense of spatial depth on a black night sky.

### Result

The final composition creates a sense of spatial depth by placing fireworks at different scales and levels of transparency.

---

## Overall Process

Simple → Preset Style → Interactive → 3D-like

I started with a single, simple firework and gradually expanded its visual and interactive possibilities. Through the four stages, the original form developed into a larger generative fireworks space.
